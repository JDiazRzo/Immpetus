# Frontend · Next.js

```bash
npm ci
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

- Páginas en `src/app`, componentes en `src/components`, tipos del contrato en `src/types/api.ts`.
- Mientras no exista el backend, los datos salen de `src/mocks/` (mismo formato del contrato).
- URL de la API en `NEXT_PUBLIC_API_URL`.
- Ojo: esta versión de Next.js trae cambios; ver `AGENTS.md` en esta carpeta.
